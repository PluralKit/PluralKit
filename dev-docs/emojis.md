## Emojis Overview
The bot attempts to use custom emojis in some places. It does this by checking the emojis the application has registered with Discord for an emoji with the corresponding name. If it can't find a custom emoji with the right name it will fallback to a default emoji shown below.

### Custom Emojis in Use
| Name | Fallback | Use |
| ---- | -------- | --- |
| LeftArrow | ⬅️ | Used in CV2 paginated lists as a button |
| RightArrow | ➡️ | Used in CV2 paginated lists as a button |
| LeftDoubleArrow | ⏪ | Used in CV2 paginated lists as a button |
| RightDoubleArrow | ⏩ | Used in CV2 paginated lists as a button |
| PageSelector | 🔢 | Used in CV2 paginated lists as a button |
